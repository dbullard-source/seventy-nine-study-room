# Seventy-Nine Study Room

Series 79 (Investment Banking Representative) study site for sports M&A advisory.
Static HTML, CSS and JavaScript; no build step, no external scripts.

Includes a Foundations track (14 plain-English finance lessons), a 150-term glossary with tap-to-define terms, 16 exam lessons mapped to the FINRA Series 79 outline, 92 practice questions, flashcards, deal calculators, a 10-week plan and a licensing guide.

Live: https://dbullard-source.github.io/seventy-nine-study-room/

Progress is stored in the browser's localStorage. Original educational questions, not FINRA exam items.
